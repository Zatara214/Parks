## Method, not code

- **[WDW Passport](https://wdwpassport.com)** — the crowd-level algorithm in
  `app/src/main/kotlin/contact/kaufman/parks/data/crowd/` follows the method they publish:
  average a curated set of established key attractions over the 10AM–5PM window, rank each
  ride against its own history, and take the mean of the *ride ranks* as the park level.
  No code and no data were taken from them; the implementation and the calibration table
  are original.

## Data sources

- **[themeparks.wiki](https://themeparks.wiki)** — wait times, park hours, showtimes,
  attraction and dining listings. A free, volunteer-run public API. Parks never polls it:
  every request is triggered by something on screen, and responses are cached.
- **[Open-Meteo](https://open-meteo.com)** — weather forecasts, fetched on demand.
  Free for non-commercial use, no API key, no user tracking.
